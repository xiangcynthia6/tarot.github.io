月映 · 韦特塔罗 — 完整网页源码

此包为本次对话最后更新的版本，包含手机端牌阵跳转修复。

使用方法
1. 完整解压 ZIP，不要在压缩包预览中打开网页。
2. 用 Chrome、Edge 或 Safari 打开 index.html 即可使用。
3. 如浏览器对本地文件有限制，可在解压目录运行 python -m http.server 8000，
   然后访问 http://localhost:8000 。这只是可选方法，不需要构建或安装 npm 依赖。
4. 部署到静态网站空间时，上传整个文件夹，确保 index.html 位于网站根目录。

文件说明
index.html：页面结构与问题输入框。
style.css：电脑与手机排版、牌面比例、桌布与翻牌样式。
app.js：随机洗牌、抽牌、正逆位、拖动、旋转、固定牌位及导航逻辑。
cards.js：78 张牌的中文正逆位释义、名称及占星对应。
spreads.js：6 种常用牌阵的位置与说明。
assets/：全部 78 张原始牌面 JPG，以及图像署名与来源许可。
SHA256SUMS.json：源码与图片校验值。

功能
自由抽牌与固定牌阵；问题输入；洗牌清空问题；牌背拖放；按顺序翻牌；
横放/竖放；手机分页选牌与点击放牌；图鉴；6 种牌阵说明。
从常用牌阵切换会重新准备牌堆，并保留问题。

联网与数据
牌面图片均在本地，不依赖图片外链。
Google Fonts 字体需要联网；断网时自动使用系统字体，不影响核心抽牌功能。
此站为纯前端，无后台、数据库、API 密钥或自动 AI 解牌接口。
输入的问题和本轮抽牌保存在当前页面内存，刷新后不保留。
